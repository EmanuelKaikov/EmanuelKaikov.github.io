# PromIT Official Site Repository (site_repo) 🎓🎬

תיקיית פרויקט נקייה ועצמאית המכילה את כל הקוד והמולטימדיה של אתר **PromIT**.

## 📁 מבנה התיקייה:
- `index.html` - דף הבית ומבנה המגזין.
- `styles.css` - עיצוב יוקרתי, פלטת צבעים, glassmorphism והתאמה להדפסת PDF.
- `script.js` - לוגיקה אינטראקטיבית, מחשבון נשף, נגן מולטימדיה ומודלים.
- `pictures/` - 41 תמונות מאירועי PromIT.
- `videos/` - 28 סרטוני וידאו ואפטר-פארטי מאירועי PromIT.
- `DEPLOYMENT.md` - מדריך חיבור דומיין אישי והעלאה לרשת.
