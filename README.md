# PromIT - המגזין הרשמי לנשף הסיום 🎓🎬

אתר התדמית והפקת נשפי הסיום היוקרתי של **PromIT - מביאים את הוליווד לישראל**.

## 🚀 תכונות עיקריות בגרסה המשודרגת:
- **עיצוב הוליוודי יוקרתי (Glassmorphism & Gold Theme):** התאמה מושלמת למותג, עם אפקטים של תאורה, זהב ואווירת פסטיבל.
- **גלריית מולטימדיה אינטראקטיבית (תמונות וסרטוני אפטר בלייב):** שילוב קובצי הווידאו והתמונות האמיתיים מאירועי PromIT.
- **מחשבון נשף אינטראקטיבי לוועד:** חישוב עלויות משוערות בזמן אמת לפי כמות תלמידים, סגנון לוקיישן, רמת קייטרינג ואטרקציות נבחרות.
- **חיוג ופנייה ישירה לוואטסאפ (`054-3534890`):** יצירת הודעות מותאמות אישית ישירות מהמחשבון ומהחבילות.
- **מעטפת ביטחון להורים ולבית הספר:** פירוט אבטחה חמושה, חובש מוסמך, הסעות מאורגנות וביטוחים.
- **תמיכה מלאה בהדפסה ושמירה כ-PDF (`window.print()`):** עיצוב מיוחד למגזין מודפס/דיגיטלי לשיתוף עם המנהלים וההורים.
- **רספונסיביות מלאה:** מותאם באופן מושלם לכל מכשירי הסלולר, הטאבלטים והמחשבים.

## 📁 מבנה הקבצים:
- `index.html` - הדף הראשי והמבנה.
- `styles.css` - עיצוב custom, פלטת צבעים, glassmorphism ומיקרו-אנימציות.
- `script.js` - הלוגיקה האינטראקטיבית, מחשבון החבילה, תפריט סלולרי ומודל הגלריה.
- `videos/` - תיקיית התמונות והסרטונים מהאירועים בשטח.
- `DEPLOYMENT.md` - מדריך מקיף להעלאת האתר לאוויר וחיבור דומיין אישי.

## 🌐 איך להריץ מקומית:
פשוט פתחו את הקובץ `index.html` בכל דפדפן (Chrome, Edge, Safari, Firefox).
